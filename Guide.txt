TEXTURPAINTER - paint 3D models with CSP, Krita or PhotoCraft
=========================================================================

You paint in your 2D painting program, Blender projects it onto the
model live. You never have to touch UVs.

Tested with: Clip Studio Paint, Krita, PhotoCraft
             Blender 5.3 and 5.2


INSTALL ONCE
------------
1. Blender: Edit > Preferences > Add-ons
2. Top right, the small arrow (v) > "Install from Disk"
3. Select the file  texturpainter.py
4. Tick "Texturpainter"
5. Done. In the 3D Viewport press N > tab "Texturpainter"

The add-on speaks the language set in Blender
(English or German, other languages show English).

The default paths for CSP and Krita are already filled in.
PhotoCraft or another program: expand the add-on > enter the path
to the .exe. If a program is installed elsewhere, change the path there.


TIP FIRST: SAVE THE BLENDER FILE
--------------------------------
Save your .blend once before you start. Then all images live next to the
.blend right away and you can stop any time and continue later.
(Forgot it? No problem either, see "Continue later".)


THE PANEL
---------
3D Viewport > press N > tab "Texturpainter". From top to bottom:

  "Clip Studio Paint"        Dropdown: pick the painting program
                             (Clip Studio Paint, Krita, PhotoCraft,
                             Custom program)
  "All-sides mode: off"      Toggle. Off = the view you see.
  / "All-sides mode: ON"     On = all sides at once (see below)
  Status box                 Shows what is going on
  "View to CSP"              Big button: sends the view to the
                             painting program
  "New view to CSP"          Same button while a view is open:
                             finishes it, sends the new one
  "All sides to CSP"         Same button with all-sides mode ON
  "Open again"               Opens the view again in the painting program
  "Discard"                  Forgets the view and removes what you
                             painted in it from the model
  "Save Blender file"        Saves the .blend with the texture

Instead of "CSP" the buttons show the program you picked,
e.g. "View to Krita".


HOW TO PAINT (ONE VIEW)
-----------------------
1. Select the model.
2. Press "View to CSP".
   -> Your painting program opens with a PSD file.
      (If it is behind Blender: click it in the taskbar.)
3. The painting program shows two layers:
     "paint"     top    -> paint HERE
     "Template"  bottom -> the image from Blender
   Click the "paint" layer and paint. Ctrl+S as often as you like.
   -> After every Ctrl+S the painting shows up on the model in Blender
      by itself after about 1 second.
4. Another side: rotate the model in Blender, press "New view to CSP".
5. Repeat.
6. At the end: "Save Blender file".
   (For a new file Blender asks where to save it.)


OPACITY OF THE PAINT LAYER
--------------------------
Feel free to set the opacity of "paint" to e.g. 70 % so you can see the
template's shading through your colour.
Blender still projects the colour at FULL opacity. The shading on the
model comes from Blender's lighting, not from your image.


ALL-SIDES MODE
--------------
Click "All-sides mode: off", it then shows "All-sides mode: ON".
Then press "All sides to CSP".

You get ONE PSD with one folder per view:

  front, front right, right, back right, back,
  back left, left, front left, top, bottom

Each folder holds "paint" (top) and "Template" (bottom).
Only "front" is visible, the others are hidden.

To switch sides:
1. Turn off the eye of the folder you are done with.
2. Turn on the eye of the next folder and expand it.
3. Click its "paint" layer. (Important! Otherwise the program keeps
   painting on the layer of the previous folder.)
4. Paint, Ctrl+S.

When you save, Blender reads ALL folders, hidden ones too, and projects
each from its direction.

IMPORTANT: Do not scale or crop the canvas in the painting program.

In the settings: 6, 8 or 10 views (default 10).

Hidden spots (armpits, inner legs, under the chin): afterwards paint them
with "All-sides mode: off": rotate the model so you can see the spot,
press "View to CSP".


CONTINUE LATER
--------------
1. Press "Save Blender file". Press Ctrl+S in CSP.
   Both may be closed now.
2. Later: open the .blend in Blender, open the PSD in CSP
   (or press "Open again" in Blender).
3. Just keep painting and press Ctrl+S. Blender picks it up as before,
   without painting anything twice.

If the .blend was not saved yet when you started, the PSD first lives in
Blender's temp folder. On the first save it moves next to the .blend
automatically. The panel then says:
  "The image now lives next to the .blend file."
  -> Press "Open again" and close the old tab in the painting program.


GOOD TO KNOW
------------
- Saving several times is fine. Nothing gets painted twice,
  not even with semi-transparent brushes.
- Erased something and pressed Ctrl+S? Then it is gone on the model too.
- Pressed "New view to CSP" without painting? No problem, it just goes on.
- "Discard" removes everything you painted in the current view.
- Accidentally painted on "Template"? It is still picked up.
- Careful: whatever you paint directly in Blender on the texture while
  a view is open in the painting program gets overwritten by the next
  Ctrl+S there. Press "Discard" or get a new view first, then paint
  in Blender.


STATUS IN THE PANEL
-------------------
  i  "Ready"                  -> rotate the model, press "View to CSP"
  ⏱  "Paint in ... + Ctrl+S"   -> paint and save in the painting program
  ✓  "On the model (time)"    -> it is on. Keep painting + Ctrl+S
                                 or rotate + "New view to CSP"
  !  red message              -> something failed, the reason is shown


SWITCHING THE PAINTING PROGRAM
------------------------------
At the top of the panel: Clip Studio Paint / Krita / PhotoCraft / Custom.
All three open and save PSD files with layers and folders.
Just save with Ctrl+S, the file stays a PSD.

Krita needs a few seconds on first start.

An update on every brush stroke (without Ctrl+S) is not possible:
Clip Studio Paint has no interface for that.


WHAT HAPPENS AUTOMATICALLY (first "View to CSP")
--------------------------------------------------
- No UVs?              -> created automatically (Smart UV Project)
- No material?         -> created
- No texture?          -> empty texture, 2048 or 4096 px (settings)
- Model already has a texture (e.g. Tripo)? -> painting goes onto it
- Blender switches to Texture Paint mode


SETTINGS (panel > expand "Settings")
------------------------------------
Capture size (view)     Longest image side for a single view (default 2048)
Image size (all sides)  Longest side of each view in all-sides mode
                        (default 2048)
All-sides views         6 / 8 / 10 (default 10)
New texture             2048 or 4096 px
Angle (view)            80. Faces tilted more than this are not painted.
Angle (all sides)       60. Not below 55, otherwise gaps remain.
Exe                     Path to the selected painting program


TROUBLESHOOTING
---------------
The brush does not paint
    -> Is the "paint" layer selected (not the folder)?
       Is the folder visible (eye on)?

"CSP not found" / "No path set for ..."
    -> Check the path in the settings.

"Nothing new painted"
    -> Nothing changed in the saved file.

"The image has the wrong size"
    -> The canvas was changed in the painting program. "Discard" and redo.

"The file is not a PSD file"
    -> Save as PSD in the painting program, not as PNG or CLIP.

Colour looks smeared at edges
    -> Look straight at the spot and paint it again with a single view.

The PSD makes the painting program slow
    -> Lower "Image size (all sides)" in the settings (e.g. 1536)
       or use 6 instead of 10 views.


WHERE THE IMAGES ARE
--------------------
Blender file saved:      next to the .blend in the folder  <name>_texturpainter
                         - the PSD files
                         - "..._templates", "templates" = copies of the templates
                         - "..._views" = views with their camera data
                         - "..._backup.npz" = texture before the round
Not saved yet:           in Blender's temp folder, moves next to the .blend
                         on the first save

The painted texture lives inside the .blend file.
So at the end: "Save Blender file".
